# Lab 1 POO — Gestão de Ligas Esportivas

Sistema legado de gerenciamento de ligas esportivas, times, jogadores e partidas.

## Como compilar e executar

```bash
cd src
javac *.java
java Main
```

## Estrutura

| Classe | Responsabilidade declarada |
|--------|---------------------------|
| `Liga` | Gerenciador central da liga |
| `Time` | Dados de um time |
| `Jogador` | Dados de um jogador |
| `Partida` | Dados de uma partida |
| `Main` | Ponto de entrada e demonstração |

## Problemas conhecidos a investigar

O sistema funciona parcialmente, mas possui problemas arquiteturais que devem ser identificados e corrigidos pela equipe.

Analise o código com atenção antes de propor qualquer refatoração.
